# ✅ Simple Todos

A clean and responsive **Todo List** application built with **HTML**, **CSS**, and **JavaScript**. It helps users organize daily tasks with a simple and intuitive interface.

---

## ✨ Features

- ➕ Add New Tasks
- ✅ Mark Tasks as Completed
- 🗑️ Delete Tasks
- 📋 Live Task List
- 💾 Local Storage Support
- 📱 Responsive Design
- ⚡ Fast and Lightweight
- 🎨 Clean User Interface

## 📖 Usage

- Type a task in the input field.
- Click **Add** to create a new task.
- Mark a task as completed when finished.
- Delete tasks that are no longer needed.
- Tasks are automatically saved using Local Storage.
